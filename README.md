# Tapia Tech | Portafolio Profesional 🚀

Portafolio personal interactivo de **Jhon Eligio Tapia Vargas**, Ingeniero de Sistemas y Desarrollador Full Stack. 

Construido con un enfoque estricto en la arquitectura limpia, rendimiento (optimizado para métricas Lighthouse) y una experiencia de usuario inmersiva.

## 🛠️ Stack Tecnológico

* **Framework:** Vue 3 
* **Build Tool:** Vite
* **Estilos:** Tailwind CSS v3 (con sistema de temas dinámico Light/Dark)
* **Animaciones Core:** GSAP (GreenSock Animation Platform)
* **Visualización de Datos:** D3.js (Físicas y simulación de nodos en el lienzo)
* **Formularios:** EmailJS (Gateway de contacto sin servidor)

## ✨ Características Principales

* **Sistema Temático Personalizado:** Arquitectura de diseño adaptable (Modo Claro/Oscuro) mediante variables CSS inyectadas dinámicamente, con efecto Glassmorphism.
* **Simulación D3.js Optimizada:** Grafo de habilidades interactivo con físicas de repulsión y colisión, optimizado con `IntersectionObserver` para suspender cálculos fuera de pantalla y ahorrar CPU.
* **Rendimiento LCP:** Implementación de `preload` y `fetchpriority` en el Hero section para carga instantánea de recursos críticos.
* **Diseño Responsivo:** Layout adaptativo usando CSS Grid fraccional, garantizando proporciones exactas en cualquier dispositivo móvil o escritorio.
